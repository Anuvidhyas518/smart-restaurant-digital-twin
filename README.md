# Smart Restaurant Digital Twin

A machine-learning-based digital twin system for predicting and reducing food waste in restaurants.

## Project Objective

The project uses restaurant data and machine learning to estimate food waste and support better food preparation and waste-management decisions.

## Main Features

- Food waste prediction
- Restaurant waste data processing
- Exploratory data analysis
- Model comparison and cross-validation
- New waste prediction
- Waste impact calculation
- Waste output estimation
- Interactive Streamlit dashboard
